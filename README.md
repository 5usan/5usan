### Projects

**[GraphRAG](https://github.com/5usan/GraphRAG)** — Knowledge-Graph-Augmented Retrieval *(thesis)*
> Designed a RAG pipeline over OWL/RDF ontologies. Entities and relations are extracted, embedded with BERT, and indexed in Neo4j. At query time, graph traversal supplements dense retrieval to improve answer grounding and reduce hallucination. Deployed via FastAPI with Docker + Singularity for HPC environments.
> `Python` · `Neo4j` · `BERT` · `RDFLib` · `FastAPI` · `Docker` · `CUDA`

**[Graph Augmentation using LLMs for Text-Attributed GNNs](https://github.com/5usan/Graph-Augmentation-using-LLMs-for-Text-Attributed-GNNs)**
> Investigated LLM-generated text features as augmented node attributes for Text-Attributed Graphs (TAGs). Evaluated impact on GNN node classification benchmarks — bridging the gap between LLM representation quality and graph structural learning.
> `Python` · `PyTorch` · `GNNs` · `HuggingFace Transformers`
